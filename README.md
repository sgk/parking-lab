# 車庫入れラボ

点数や時間制限のない、初心者向けの車庫入れシミュレーターです。外部ライブラリ、外部フォント、通信、アカウント登録は不要です。

[ブラウザで試す](https://parking-lab-sgk-20261106.playfuldart.chatgpt.site) · [GitHub](https://github.com/sgk/parking-lab)

## ローカルで使う

```sh
npm run dev
```

`http://localhost:4173` をブラウザで開きます。

## 操作

- ボタン類を除く練習画面をマウス・タッチで押している間、現在の自車に対する位置から速度とハンドル角度を決めます。開始位置やドラッグ距離は使いません。クリック・タップだけの微速前進は廃止しました。押したまま位置を変えると、前後・左右の操作が変わります。
- 車の中心を左右に横切る黄色の停止帯の中は速度ゼロです。帯より車の前側を押すと前進、後ろ側なら後進です。帯の境界からの距離に比例して速度を上げ、前後軸に沿った画面の長さの半分で最大2m/s（7.2km/h）になります。停止帯は中心から前後それぞれ、同じ画面長の5％です。
- 車の中心から前後に延びる緑の直進帯の中はハンドルと前輪が正確に直進になります。中心から左右それぞれ、左右軸に沿った画面の長さの5％が不感域です。帯の外では切れ角がゼロから連続して増え、同じ画面長の半分で左右それぞれ最大1.5回転です。停止帯の中でもステアリングだけ操作できます。
- 両モード・全体図とも現在の車の中心と向きを毎フレーム基準にします。帯も車に追従し、地図固定では車が移動・旋回するたび、同じ押下位置に対する操作量も変化します。自車固定では画面上が前進、下が後進です。離すと即停止し、ハンドル角度は保持します。
- 初期表示は自車固定です。地図固定／自車固定を切り替えられます。自車固定では車の位置と向きを固定します。表示は横に車幅5台分、縦に車長3台分が収まる倍率で拡大します。地図固定では操作中の地図を固定し、マウス・指を離した時や操作が中断された時に、自車が中央へ来るよう表示中心だけを更新します。車の位置・向きや地図の向きは変更しません。手動の位置戻しボタンはありません。
- ハンドルの中央戻し、軌跡と予測ガイドの表示切り替え、リセットがあります。
- 接触時には移動を止めます。接触位置から離れる方向への操作は可能です。
- 車や外周の壁に接触すると、約0.5秒の「ブー」音が鳴ります。同じ操作で押し続けても連打しません。指を離し、再びぶつかる方向に操作すると、その場でも再度鳴ります。押し続けたままでも8cm以上離れて再接触すると再び鳴ります。開始モーダルはなく、マップを選ぶとすぐに運転できます。練習画面を押した時に、同じ音声処理を無音で有効にします。音声の有効化待ちで運転を止めません。衝突音は操作中に接触した瞬間に鳴り、指を離す必要はありません。音テスト・衝突音・成功音は共通の再生処理を通り、各イベントで音声が停止中なら再開完了を待ってから一度だけ再生します。失敗時に別の再生方式へ切り替えたり、自動で繰り返したりしません。「音をテスト・有効にする」ボタンは、音声の有効化完了を待ってチャイムを再生します。「衝突音だけテスト」で同じ衝突音を単独再生できます。音声波形の確認表示はWeb Audioの出力直前の信号を観測し、再生予約だけで波形生成を断定しません。波形があっても端末スピーカーからの可聴音は保証できず、端末やブラウザがミュートの場合は聞こえません。
- 「駐車場の寸法」でロット幅（2.2〜4.0m）、ロット奥行き（4.8〜8.0m）、通路幅（3.0〜12.0m）を0.1m単位で設定できます。各項目の「−」「＋」で増減でき、数値の直接入力も可能です。「寸法を適用して最初から」で駐車枠・周囲の車・接触判定をまとめて更新し、自車と軌跡をリセットします。通常の「最初から」は現在の寸法を保持します。
- オレンジの直線が、自車中心と目的の駐車ロット中心を結びます。凡例には中心同士の直線距離をメートルで表示します。地図固定・車固定のどちらにも対応します。

## 駐車場の切り替え

最初に表示されるマップ一覧で、地形のサムネイルを押すとプレイ画面へ進みます。次の10種類から選べます。

| 駐車場 | 練習する条件 |
| --- | --- |
| 直角駐車・向き自由 | 広い通路で前向き・バックの両方 |
| バック駐車指定 | 車の前を通路側へ向ける |
| 前向き駐車指定 | 車の前を奥の壁側へ向ける |
| 左側への縦列駐車 | 右向き走行から、左側の前後車両の間へ |
| 右側への縦列駐車 | 左向き走行から、右側の前後車両の間へ |
| 行き止まり・左端の枠 | 左の壁ぎわの枠へバック駐車 |
| 行き止まり・右端の枠 | 右の壁ぎわの枠へバック駐車 |
| 狭い通路でバック駐車 | 切り返しと前側の振れ幅 |
| 向かいにも車がある駐車場 | 対向する駐車列との間隔 |
| 斜めの駐車枠 | 60°の枠へ前向き駐車 |

一覧とプレイ画面は別の画面です。「マップ選択へ戻る」で一覧へ戻れ、ブラウザの戻る・進むも使えます。一覧では車は動かず、運転操作を受け付けません。サムネイルは実際の駐車場と同じデータから描き、緑の自車・周囲の車・点線の目標枠・壁の位置を確認できます。

マップを選ぶと車と軌跡をリセットし、選んだ駐車場の標準寸法に切り替えます。その後の寸法変更では選択中の駐車場を保持します。縦列では「奥行き」の代わりに「縦列枠の長さ」を設定します。「この駐車場の標準に戻す」も選択を保持します。

向き指定がある場合は、点線枠内の矢印が車の前向きです。逆向きでは成功になりません。前向き／バック指定は最終的な車の向きで判定し、途中の切り返しは許容します。向き自由の駐車場では両方向を受け入れます。

「全体図を見る」で北を上にした駐車場全体を確認でき、閉じると元の拡大表示に戻ります。視点切り替えでも全体図を閉じます。地図固定で全体図を見ながら操作した場合は全体表示を維持し、閉じた時には自車が中央に表示されます。プレイ画面の初期表示は引き続き自車固定です。`#maps` が一覧、`#play/parallel-left` のようなURLが各プレイ画面です。

## モデル

車長4.4m、車幅1.8m、ホイールベース2.6m、最大前輪角36°の低速自転車モデルです。速度は現在の自車中心から見た前後位置と停止帯の境界との距離に比例し、時間積分して位置を更新します。左右の前輪には同じ操舵角を与えます。実車のアッカーマン機構、慣性、エンジン特性によるクリープ、タイヤの滑り、ブレーキ距離は再現しません。

後輪2本の軌跡を記録します。予測ガイドは現在のハンドル角度を維持したときの後輪の経路で、停止時には前進方向を示します。目的地中心には自車と同じ4.4m×1.8mの点線枠を表示します。点線枠の中心から左右20cm・前後35cm以内、枠との傾き8°以内で、車全体がロット内に収まり、接触せず、指・マウスを離して停止していると駐車成功になります。指を置いたままアクセルをゼロにしても成功音は鳴りません。向き自由の駐車場では前向き・後ろ向きのどちらも受け入れます。指定のある駐車場では矢印と同じ向きに合わせます。成功音は指を離したイベントで音声の再開完了を待って再生します。再生処理が成功した場合だけ再生済みに記録し、再生できなかった場合はメッセージで知らせます。明るいチャイムは成功した操作ごとに一度鳴ります。同じ練習内でも次の操作で成功すれば再び鳴ります。指がブラウザにキャンセルされた場合に成功表示だけが出ることはありません。

## 実Chromeでの音声検証

2026-11-06、公開版に対してLinuxの実Chrome 156を隔離した一時プロファイルで実行しました。マウス操作とChromeのタッチエミュレーションで、壁への衝突、同じ壁への再操作、音声停止・放置後の衝突、成功時の再生を確認しています。

```sh
node tests/browser-qa.mjs
node tests/browser-qa.mjs --no-recording
```

録音ありの8ケースすべてで非無音の音声を検出し、録音を組み込まない8ケースでも、その操作による新しい波形を確認しました。成功時は音声処理の検証に集中するため、ブラウザデバッガーで車を目標位置へ配置しています。録音はWeb Audioの生成音で、マイクは使用していません。

結果・録音・スクリーンショットは `tests/artifacts/` にあります。`test-summary.json` が概要です。強制的なタブ凍結の別実験ではタッチ入力が応答しなくなり、このケースは成功件数に含めていません。

エージェントの環境にはAndroid端末が接続されておらず、Android実機やスピーカーから実際に音が出るかは未検証です。2026-11-07に、利用者からAndroidでも音が出ているとの報告がありました。Linux Chromeでは報告された無音を再現できず、Android側の原因特定・解消確認には至っていません。

## Cloudflare Workers

`dist/` が配信する静的ファイル一式です。自分のCloudflareアカウントに公開する場合の設定は `wrangler.jsonc` にあります。認証は利用者自身でCloudflareの公式手順に従って行い、認証情報をこのリポジトリに保存しないでください。

```sh
npx wrangler deploy
```

Sites経由の公開先識別子は `.openai/hosting.json` に保存されます。
