# 車庫入れラボ

点数や時間制限のない、初心者向けの車庫入れシミュレーターです。外部ライブラリ、外部フォント、通信、アカウント登録は不要です。

## ローカルで使う

```sh
npm run dev
```

`http://localhost:4173` をブラウザで開きます。

## 操作

- ボタン類を除く画面の任意の場所で、マウスまたは指を押してドラッグします。
- 開始位置から上に動かすと前進、下に動かすと後進します。上下100pxで最高速度7.2km/hです。
- 練習画面内の横の絶対位置がハンドル角度になります。中央の縦線で直進、左右の端でそれぞれ最大1.5回転です。
- 斜めにドラッグすれば、速度とハンドルを同時に操作できます。
- タップだけでもハンドル角度を変更できます。上下にドラッグしなければ車は動かず、離すと即停止します。ハンドル角度は保持します。
- 地図固定／車固定を切り替えられます。車固定では車の位置と向きを固定します。表示は横に車幅5台分、縦に車長3台分が収まる倍率で拡大します。画面の縦横比による余白も表示します。地図固定の表示中心は切り替え時・リセット時の車の位置で、「車の位置へ」で移動できます。
- ハンドルの中央戻し、軌跡と予測ガイドの表示切り替え、リセットがあります。
- 接触時には移動を止めます。接触位置から離れる方向への操作は可能です。
- 「駐車場の寸法」でロット幅（2.2〜4.0m）、ロット奥行き（4.8〜8.0m）、通路幅（3.0〜12.0m）を0.1m単位で設定できます。「寸法を適用して最初から」で駐車枠・周囲の車・接触判定をまとめて更新し、自車と軌跡をリセットします。通常の「最初から」は現在の寸法を保持します。
- オレンジの直線が、自車中心と目的の駐車ロット中心を結びます。凡例には中心同士の直線距離をメートルで表示します。地図固定・車固定のどちらにも対応します。

## モデル

車長4.4m、車幅1.8m、ホイールベース2.6m、最大前輪角36°の低速自転車モデルです。速度は上下のドラッグ距離に比例し、時間積分して位置を更新します。左右の前輪には同じ操舵角を与えます。実車のアッカーマン機構、慣性、クリープ、タイヤの滑り、ブレーキ距離は再現しません。

後輪2本の軌跡を記録します。予測ガイドは現在のハンドル角度を維持したときの後輪の経路で、停止時には前進方向を示します。緑の枠に車全体が収まるとメッセージを表示します。


## Cloudflare Workers

`dist/` が配信する静的ファイル一式です。自分のCloudflareアカウントに公開する場合の設定は `wrangler.jsonc` にあります。認証は利用者自身でCloudflareの公式手順に従って行い、認証情報をこのリポジトリに保存しないでください。

```sh
npx wrangler deploy
```

Sites経由の公開先識別子は `.openai/hosting.json` に保存されます。
